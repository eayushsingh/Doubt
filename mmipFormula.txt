COMPLEX FOURIER SERIES (CFS)

1. Complex Fourier Series

x(t) = Σ[n=-∞ to ∞] C_n e^(j n ω₀ t)

where:

ω₀ = 2π / T₀


2. CFS Coefficient

C_n = (1 / T₀) ∫[-T₀/2 to T₀/2] x(t)e^(-j n ω₀ t) dt


3. Relation Between TFS and CFS

For n > 0:

C_n = (a_n - j b_n) / 2

C_(-n) = (a_n + j b_n) / 2

Hence:

a_n = C_n + C_(-n)

b_n = j[C_n - C_(-n)]


4. DC Component

C_0 = a_0


5. Magnitude of CFS Coefficient

|C_n| = sqrt[(a_n/2)^2 + (b_n/2)^2]

Also:

|C_n| = |C_(-n)|


6. Phase of CFS Coefficient

∠C_n = tan^(-1)(b_n / a_n)

∠C_(-n) = 2π - ∠C_n


7. Real Signal Property

For real x(t):

C_(-n) = C_n*


8. Symmetry of Magnitude

|C_(-n)| = |C_n|


9. Fourier Transform Pair

X(ω) = ∫[-∞ to ∞] x(t)e^(-jωt) dt

x(t) = (1 / 2π) ∫[-∞ to ∞] X(ω)e^(jωt) dω


10. Relation Between CFS and Fourier Transform

As T₀ → ∞:

ω₀ = 2π/T₀ → 0

nω₀ → ω

Therefore:

Σ → ∫

and the CFS becomes the Fourier Transform.


11. Sinc / Sampling Function

Sa(x) = sin(x) / x

Sa(0) = 1


12. First Zero of Sa(x)

Sa(x) = 0

=> sin(x) = 0

=> x = ±π, ±2π, ±3π, ...

First zero:

x = ±π


13. Rectangular Pulse

For:

x(t) = A,    |t| ≤ τ/2
x(t) = 0,    |t| > τ/2

Fourier Transform:

X(ω) = Aτ Sa(ωτ/2)


14. First Spectral Zero of Rectangular Pulse

ωτ/2 = ±π

=> ω = ±2π/τ

Therefore:

|ω₀| = 2π/τ


15. Fundamental Frequency

f₀ = 1/T₀

ω₀ = 2πf₀ = 2π/T₀
